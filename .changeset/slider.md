Add `Slider`, for a value in a range such as volume or zoom, on the native `<input type="range">`. Control it with `value` and `onValueChange`, or let it keep its own value from `defaultValue`; `min`, `max`, `step` and `largeStep` set the range and steps. `formatValue` gives screen readers the value as text, such as "−6 dB". The arrow keys, Page Up and Page Down, Home and End work the same in every browser, and the slider is mirrored in right-to-left text. Restyle it with the `--hm-slider-*` tokens.
